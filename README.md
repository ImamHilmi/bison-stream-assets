# BISON Stream Assets

Repository ini digunakan untuk menyimpan berbagai asset yang digunakan dalam livestream, terutama untuk overlay, widget, dan elemen visual lainnya.

Repository ini dibuat agar asset livestream dapat digunakan dan dikelola bersama dengan lebih mudah.

## Purpose

Repository ini berfungsi sebagai centralized storage untuk asset livestream seperti:

- Chat Box background
- Overlay background
- Streaming graphics
- Widget assets
- Image dan GIF untuk OBS / Streamlabs
- Asset visual lain yang digunakan dalam livestream
